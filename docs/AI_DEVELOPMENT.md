# AIを使った開発と確認

Actlasを、AIを活用した開発の制作実績として共有するための公開版です。完成画面だけでなく、API、リアルタイム通信、認可、DB設計を読めるようにしています。

## この公開版の整備で行ったこと

1. 公開する目的と範囲を人が決める。実際のコードを見せ、翻訳・AI要約・初回ログイン制御は公開デモから外す方針を指定。
2. AIでコードを調べる。公開を避ける情報と、READMEに書ける実装上の事実を分担して確認。
3. 公開用フォルダを独立させる。実画像・本番設定・元Git履歴を持ち込まず、必要なソースだけを移す。
4. AIによる変更を、型チェック、lint、ビルド、専用DBの初期化、HTTPとSocket.IOの動作確認で検証。
5. 実装がある機能、今回確認した範囲、外部連携や実機での追加確認が必要な範囲を分けて記載。

この説明は今回の公開版整備についてのものです。過去の全機能について、AIと本人の担当割合、作業時間、品質改善率などを推測して記載していません。

## レビュー時に見ていただきたい判断

- メール認証を省略しても、パスワード・JWT・先生と生徒の認可を残す。
- AIを呼ぶボタンだけでなく、自動開始とサーバーへの直接リクエストも止める。
- カメラ・音声の品質は、APIテストだけで確認できたと扱わない。
- 確認用DBを専用のlocalhostに限定し、本番データの流用を避ける。
- 公開用の秘密値を生成し、コミット候補に実値を含めない。
- 修正後に検証し、確認できていないことは[検証記録](VERIFICATION.md)に明記する。

AIの提案を採用するだけでなく、依頼の範囲、情報の取り扱い、認可、実行結果を確認することを重視しています。
